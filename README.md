# Bahn Lernen – 14-Tage-Lernplattform

Eine kleine Vue/Vite-Lernplattform auf Basis der hochgeladenen DB InfraGO Ausbildungspräsentationen (September 2026).

## Start

```bash
npm install
npm run dev
```

Dann die von Vite angezeigte lokale Adresse öffnen.

## GitHub Pages

Das Projekt kann als normales Vite/Vue-Projekt in ein GitHub-Repository gelegt werden. Für GitHub Pages kann später ein Pages-Workflow ergänzt werden; bei einem Repository-Unterpfad muss ggf. `base` in `vite.config.js` gesetzt werden.

## Enthalten

- 14 vorgeplante Lerntage
- Lernziele und Priorisierung: Muss / Verstehen / Kennen
- Karteikarten mit Flip-Funktion
- Multiple-Choice-Quiz pro Tag
- Fortschritt wird lokal im Browser gespeichert
- Vorheriger/nächster Tag
- Responsive Oberfläche für Desktop und Mobil

## Didaktische Struktur

1. Betriebsstellen
2. Zugmeldestellen und Zugfolgestellen
3. Zugmeldeverfahren
4. Wortlaute
5. Haupt-, Vor- und Zugsignale
6. Zusatz- und Lf-Signale
7. Wochenprüfung
8. Fahrwegprüfung
9. PEPSI, Fahrstraße und Signalabhängigkeit
10. Streckenblock
11. Räumungsprüfung, Zugschluss und Bahnhofsblock
12. Stellwerke und ESTW
13. Fahrplan und Zuginformationen
14. Abschlussprüfung

## Hinweis

Die Inhalte sind bewusst auf den Lernstand und die Schwerpunkte der Präsentationen zugeschnitten. Tiefe technische Details zu Blockfeldarten werden nicht künstlich erweitert, weil die Ausbildungsunterlagen selbst hier einen grundlegenden Überblick vorsehen.
